# کورس آن لائن ایڈمیشن و رجسٹریشن پورٹل

یہ ایک مکمل، خوبصورت اور خودکار آن لائن داخلہ فارم اور مینیجمنٹ سسٹم ہے جس میں دینی مدارس کے طلباء کے لیے 50 فیصد خصوصی رعایت، شناختی کارڈ، طالب علم کی تصویر، اور فیس ادائیگی کی رسید شامل ہے۔

---

## 🌟 نمایاں خصوصیات

1. **طالب علم کا داخلہ فارم (اردو انٹرفیس)**:
   - مکمل نام، والد کا نام، قومی شناختی کارڈ نمبر / ب فارم (13 ہندسوں کی خودکار فارمیٹنگ)
   - واٹس ایپ اور موبائل نمبر، ای میل، شہر، اور مکمل پتہ
   - تعلیمی قابلیت (حفظ قرآن، میٹرک، ایف اے، بی اے، وغیرہ)

2. **طالب علم کی تصویر (Passport Size Photo)**:
   - لائیو پری ویو کے ساتھ پاسپورٹ سائز تصویر اپلوڈ کی سہولت۔

3. **دینی مدرسہ طالب علم ڈسکاؤنٹ (50% رعایت)**:
   - فارم میں *"کیا آپ کسی دینی مدرسے کے طالب علم ہیں؟"* کا آپشن۔
   - منتخب کرنے پر **فیس خودکار طور پر 50 فیصد کم** ہو جاتی ہے۔
   - مدرسہ / جامعہ کا نام، کلاس، اور مدرسہ تصدیقی کارڈ اپلوڈ کا خودکار آپشن۔

4. **فیس ادائیگی اور رسید اپلوڈ**:
   - اصل فیس، ڈسکاؤنٹ، اور ادا شدہ رقم کا لائیو حساب۔
   - ایزی پیسہ، جاز کیش اور بینک اکاؤنٹ کی تفصیلات (کاپی بٹن کے ساتھ)۔
   - ٹرانزیکشن آئی ڈی (TID) اور ادائیگی کی رسید / سکرین شاٹ اپلوڈ۔

5. **ڈیجیٹل ایڈمیشن سلپ (Digital Slip)**:
   - فارم سبمٹ ہوتے ہی طالب علم کے سامنے باضابطہ تصدیقی سلپ ظاہر ہوتی ہے جسے وہ پرنٹ یا پی ڈی ایف بنا سکتا ہے، اور ایک کلک پر ایڈمن کو واٹس ایپ کر سکتا ہے۔

6. **ایڈمن کنٹرول پینل (Admin Dashboard)**:
   - ایڈمن پورٹل: `http://localhost:3000/admin.html`
   - **ڈیفالٹ پاس ورڈ**: `admin123`
   - تمام طلباء کی فہرست، تصاویر، شناختی کارڈز اور فیس رسیدیں دیکھنے کی سہولت۔
   - داخلہ منظور (Approve) یا مسترد (Reject) کرنے کا بٹن۔
   - صرف مدرسہ کے طلباء یا صرف زیرِ التواء درخواستیں فلٹر کرنے کی سہولت۔
   - ایک کلک پر تمام ڈیٹا Excel / CSV میں ڈاؤنلوڈ کرنے کی سہولت (اردو سپورٹ کے ساتھ)۔
   - کورس کا نام، فیس کی رقم اور اکاؤنٹس ایڈمن پینل سے تبدیل کرنے کی سہولت۔

---

## 🚀 سسٹم چلانے کا آسان طریقہ

### طریقہ 1: ڈبل کلک کے ذریعے
فولڈر میں موجود فائل **`چلائیں (Start Server).bat`** پر ڈبل کلک کریں۔ یہ خود بخود سرور چلا کر آپ کے براؤزر میں پورٹل کھول دے گا۔

### طریقہ 2: کمانڈ لائن کے ذریعے
ٹرمینل / پاور شیل کھولیں اور یہ کمانڈ چلائیں:
```bash
node server.js
```

## ⚙️ فیس اور اکاؤنٹس میں تبدیلی کا طریقہ

1. ایڈمن پینل میں لاگ اِن ہو کر اوپر موجود **"سیٹنگز و فیس"** بٹن دبائیں، یا
2. فولڈر میں موجود `data/config.json` فائل کو کھول کر اپنی مرضی کے مطابق فیس، اکاؤنٹ نمبر اور پاس ورڈ تبدیل کر لیں۔
